# Downloaded-document redistribution review

The Apache-2.0 license for this repository covers project source code; it does not
automatically grant redistribution rights for third-party documents collected by the tool.

Current public-snapshot decision (2026-07-15): no generated datasets, chunks, units, logs,
discovery results, Wiki exports, or downloaded PDF/DOCX/XLSX source documents are intended
to be included. They remain runtime artifacts excluded by `.gitignore`.

Before adding any downloaded document:

1. Record its source, owner, applicable license/terms, and whether redistribution and
   modification are permitted.
2. Record attribution and notice requirements.
3. Obtain legal/owner approval when terms are missing or ambiguous.
4. Prefer synthetic fixtures or metadata-only examples when redistribution is unnecessary.
5. Add the approved artifact deliberately and preserve its review record.

An artifact with an unknown or private source must not be committed.
